实际 HTTP 验证了本地与外部头像的 PNG 类型与尺寸、参数和方法错误，以及删除的空密钥、错误密钥、`prarms` 拼写、数值字符串 UID、不存在用户、成功删除和另一用户不受影响。多表删除失败回滚由真实数据库事务用例验证。
