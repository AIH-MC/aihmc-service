# M0 接口与兼容性基线

## 已验证的行为

当前 HTTP 参考见 `legacy-http-baseline.json`，对应源码版本见 `legacy-source-sha256.json`。测试运行于原入口的独立副本、合成用户和系统已有 MariaDB 的独立测试库，没有对业务账号发出登录或删除请求。

| 项目 | 当前结果 | 迁移约束 |
| --- | --- | --- |
| 根路径 | GET、POST 均返回提示 JSON | 保留入口未限制方法的行为 |
| 初始化接口 | GET 200，POST 405 | 保留状态与错误 JSON 字段 |
| 未匹配路径及初始化路径带查询串 | 返回初始化 JSON | 不默认改为 404 |
| 有效、无效令牌验证 | 分别为 204 空体、403 JSON | 不给 204 响应写 JSON |
| 角色查不到 | profile 接口为 204，名字接口为 404 | 分接口保持差异 |
| unsigned 缺省与字符串 0 | 包含签名 | 使用 PHP 字符串真值语义 |
| unsigned 字符串 false | 不包含签名 | 不使用 Go 布尔解析替换 |
| 两个名字查询路径 | 对同一角色返回相同 id 与 name | 保留两个入口 |
| join 与 hasJoined | join 204，成功查询 200，不匹配会话 204 | 保留状态序列 |
| hasJoined 的 IP 参数 | 已建立会话上，不匹配 IP 仍返回 200 | 不擅自新增 IP 限制 |
| 无效令牌失效请求 | 204 空体 | 保留幂等结果 |
| 删除鉴权 | 错误密钥 403，空密钥 400 | 保留鉴权边界与 `prarms` 请求字段 |

## 协议向量

`legacy-protocol-vectors.json` 使用虚构用户名、UID、客户端令牌、UCenter nonce 与 secret。访问令牌、profile ID 和 UCenter 签名由原 PHP 函数生成，RSA 签名以临时密钥对生成并由 OpenSSL 验证。Go 实现必须读取这些已保存的向量进行独立对照，不能只用自身实现生成预期值。

现有数据库的材质字符串需原样保存和签名。普通 JSON 允许无意义空白和键顺序差异；Base64 材质字符串和签名输入不适用此归一化。

## 图像向量

`../tests/testdata/` 使用合成的彩色皮肤和包含透明度变化的帽子层，覆盖两种皮肤高度与整倍数、非整倍数缩放。对照解码后像素，而非 PNG 压缩字节。M4 已补充 slim、完全透明帽子层与损坏 PNG 用例，十组头像参考逐像素通过。

## 尚未关闭的验收项

1. 成功登录、重复登录、刷新、失效、退出和成功删除的受控上游序列已通过，M0 基线为 38 项，M5 补充本地头像 HTTP 后现有对照为 39 项。已有材质记录的重复登录未出现身份不一致，撤回相关修正建议。
2. 未获行为变更授权，刷新按现有 clientToken 范围处理、重复登录复用已有 accessToken，保留单用户令牌模型；不自行修复潜在的共享 clientToken 更新范围问题。相关改变需另行确认。
3. 现网网关、直接 PHP 访问、静态资源响应头及缓存配置。
4. 真实 UCenter 测试环境、启动器和服务端版本、上线访问方式与窗口。
5. 切换允许中断时长、观察窗口、成功率及延迟回退阈值。尚未约定，不以自行设定的数值充当验收标准。

M0 本地自动验收通过，现网资料与阈值标记 MANUAL/PENDING，作为 M5、M6 的前置条件，不阻塞不依赖这些资料的代码迁移。真实环境检查不能被本地基线替代。
